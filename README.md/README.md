# Doomscroll — The Internet in One Word

One word for the whole internet: **Doomscroll**.

The internet at 2 a.m. is not a library, a marketplace, or a town
square. It is one thumb, one feed, and bad news that never ends.
This entry says so in a single word — funny on its own, true of the
internet as a whole, and short enough to land in one beat.

## Run

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (UTF-8, 10 characters) and
prints it. The word is the whole entry: no explanation, no extra
text — the gate reads the file exactly as written.
